# Padrões Aprendidos — Email

## Clientes

### Padrão: Idioma Preferido
- Clientes de Portugal → preferem português
- Clientes de Espanha → preferem espanhol
- Clientes de LATAM → espanhol com "usted"
- Clientes de Catalunha → catalão ou espanhol (perguntar)

### Padrão: Tempo de Resposta
- Orçamentos: responder em < 4h (taxa de conversão maior)
- Suporte: < 2h para crítico, < 24h para normal
- Follow-up: máximo 1x por semana

### Padrão: Tom por Indústria
- Restauração/TPV → mais prático, direto
- E-commerce → focar em conversão e métricas
- SaaS/B2B → mais técnico, detalhado
- Pequeno negócio → mais próximo, exemplos simples

## Aprendizados

- 2026-05-18: Primeira versão do NEXO Mail lançada com Gmail OAuth2
- Templates com variáveis dinâmicas funcionam melhor que texto genérico
- Clientes preferem receber orçamento em 24h mesmo que aproximado

## Decisões

- Sempre usar rascunho para aprovação do admin (nunca enviar direto pela IA)
- Manter histórico de threads para contexto em respostas futuras
