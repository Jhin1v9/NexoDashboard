## ✅ O que foi entregue

### Backend
- `GET /api/workspace/clients/:id/content` — Lê arquivo textual (limite 5MB, proteção path traversal)
- `PUT /api/workspace/clients/:id/content` — Salva arquivo textual
- `buildDashboardContext()` — Quando `contextModule === 'workspace'` + `contextFile`, lê o arquivo e injeta até 4000 chars no prompt da Luna
- `contextFile` repassado em `/api/luna/chat` e `/api/luna/threads/:id/messages`

### Frontend
- `WorkspaceFileViewer.jsx` — Componente novo/reescrito com:
  - **Syntax highlighting:** `highlight.js` (importação seletiva — 15 linguagens: JS, TS, JSON, CSS, Python, PHP, SQL, YAML, XML, Bash, Dockerfile, GraphQL, Markdown, Plaintext)
  - **Modo Preview/Código:** Toggle para Markdown, HTML e arquivos de código
  - **Indicador de alterações não salvas:** ● laranja no header + subtítulo
  - **Atalhos de teclado:** `Ctrl+S` salvar, `ESC` fechar viewer
  - **Scrollbars customizadas:** `.custom-scrollbar` com thumb `#2a2a3e` e hover `#3a3a4e`
  - **Preview Markdown:** Headers, bold, italic, listas, links, code blocks, blockquote, hr
  - **Preview HTML:** iframe com sandbox + botão "Abrir no navegador"
  - **Botão Luna:** Abre `/luna?context=workspace&id=<id>&file=<path>` com contexto enriquecido
- `Workspace.jsx` — Integração do viewer (preview panel + double-click)
- `LunaControl.jsx` — Lê `file` dos query params, envia `contextFile` em mensagens
- `index.css` — Scrollbars customizadas + overrides do `.hljs`

## 🐛 Bugs encontrados e corrigidos

1. **Fundo branco do textarea** — `bg-nexo-dark` e `text-nexo-light` não existem no tema Tailwind. Corrigido para `bg-nexo-bg` / `text-nexo-text`.
2. **Backend não reiniciado** — Processo Node antigo (PID 242467) rodava sem os novos endpoints. Corrigido com `kill` + reinício.
3. **Vite argumentos** — `npm exec vite --port 3457` não passava args corretamente. Corrigido para `node_modules/.bin/vite --port 3457 --host 0.0.0.0`.
